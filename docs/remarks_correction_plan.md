# План корректировки замечаний по документации и ИИ-ассистенту

## Уже закрыто в текущей доработке

1. Панель «Проверка S3 загрузки» ограничена вкладкой «Документация»: на остальных экранах карточка автоматически удаляется из DOM.
2. Для загрузки документов исправлен источник JWT-токена: FMS, дерево файлов и AIUploadModal теперь в первую очередь используют `cm_token`, который сохраняет текущая авторизация приложения.
3. В панели «Проверка S3 загрузки» добавлена зона drag-and-drop. При перетаскивании файл подставляется в input, обозначение автоматически берётся из имени файла, после чего запускается загрузка.
4. В основном меню добавлена вкладка «ИИ ассистент» с полноценной страницей чата: беседы сохраняются отдельно для пользователя, можно создавать, переключать и удалять беседы; список автоматически группируется по текущему строительному объекту.
5. Добавлено серверное хранение истории ИИ-бесед (`ai_conversations`, `ai_messages`) и API для списка бесед, сообщений, создания, переименования и удаления; frontend использует серверную историю и переключается на локальный резерв только при недоступности API.

## Дальнейший план по требованиям загрузки документации

### Backend/FMS

1. Расширить `/api/v1/files/upload` полями `doc_type`, `designation`, `source_page`, `registry_row_id`, `detected_document_date`, `detected_revision` и `hash`.
2. Добавить вычисление и сохранение SHA-256 на backend после подтверждения загрузки, чтобы проверка дублей не зависела от браузера.
3. Реализовать поиск дублей и близких документов по:
   - SHA-256;
   - имени/обозначению;
   - извлечённому тексту;
   - дате документа и номеру редакции/версии.
4. Доработать версионирование: для `update` создавать новую версию связанного файла, увеличивать `version`, переносить старую версию в `file_versions`, а для старого загружаемого документа использовать действие `archive_as_previous`.
5. Доработать обновление ссылок из ИРД, ведомости П/Р и других реестров: хранить не только `designation`, но и явные `file_id`, `version`, `storage_key`, историю замены и источник решения пользователя.
6. Добавить отдельный audit trail: кто загрузил файл, что предложил ИИ, что подтвердил пользователь, какие ссылки были изменены.

### AI/OCR/RAG

1. Подключить OCR/парсинг PDF и изображений: PDF text layer, OCR для сканов/картинок, распознавание таблиц и печатей при необходимости.
2. Сохранять извлечённый текст в индекс проекта и привязывать его к версии файла.
3. Реализовать AI-анализ перед подтверждением:
   - классификация типа документа;
   - извлечение обозначения, даты, номера версии/изменения;
   - сравнение с существующими файлами;
   - предложение папки;
   - предупреждение о старом документе, если в хранилище уже есть более новый.
4. Возвращать в UI структурированный результат: `suggested_folder`, `version_action`, `duplicate_candidates`, `newer_candidates`, `affected_links`, `explanation_for_user`, `requires_human_review`.
5. Запрещать автоматическую замену ссылок без явного подтверждения пользователя.

### Frontend/UX

1. В AIUploadModal показать найденные дубли, более новые документы, затронутые ссылки и историю версий до подтверждения.
2. Добавить сценарии подтверждения:
   - «сохранить как новый файл»;
   - «обновить текущую версию»;
   - «сохранить как предыдущую версию»;
   - «отправить в архив»;
   - «отмена».
3. После подтверждения автоматически обновлять дерево/таблицу FMS и подсвечивать изменённые ссылки в ИРД/ведомостях.
4. Добавить прогресс стадий: загрузка → OCR → AI-анализ → проверка дублей → подтверждение → обновление ссылок.

## Дальнейший план по полноценному ИИ-чату

1. Доработать серверную историю бесед: добавить полнотекстовый поиск, пагинацию сообщений, мягкое удаление и админский аудит доступа.
2. Расширить API истории бесед вложениями, цитатами источников и быстрым переносом беседы между проектами.
3. При создании проекта автоматически создавать или подключать проектную базу знаний: документы, реестры, графики, СВОР, протоколы, сметы и шаблоны.
4. Синхронизировать список проектов/папок на вкладке ИИ ассистента с тем же источником, что и основное проектное меню.
5. Реализовать серверное объединение бесед по проектам и поиск по истории.
6. Добавить цитирование источников ответа: документ, версия, страница/лист, строка реестра, дата актуальности.
